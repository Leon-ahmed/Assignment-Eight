# SunCart – Summer Essentials Store



## Project Overview

SunCart is a modern summer-themed eCommerce platform where users can explore and purchase seasonal products such as sunglasses, summer outfits, skincare products, beach accessories, and more. Users can browse products, view detailed information, and access protected features after authentication.

## Purpose

The purpose of this project is to provide a smooth and responsive online shopping experience for summer essentials while implementing authentication, protected routes, user profile management, and modern UI design using Next.js and Tailwind CSS.

## Key Features

- Responsive design for mobile, tablet, and desktop devices.
- Summer-themed modern user interface.
- Hero section with summer sale promotions.
- Popular products section displaying featured products.
- Product details page protected by authentication.
- User registration with name, email, photo URL, and password.
- User login using email and password.
- Google authentication using BetterAuth.
- User profile page displaying name, email, and profile photo.
- Summer care tips section.
- Top brands showcase section.

## Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/Leon-ahmed/Assignment-Eight.git
```

2. Navigate to the project folder

```bash
cd suncart
```

3. Install dependencies

```bash
npm install
```

4. Configure environment variables

Create a `.env` file and add the required environment variables.

5. Run the development server

```bash
npm run dev
```

6. Open the application

```bash
http://localhost:3000
```
